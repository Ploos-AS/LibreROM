# LibreROM M2.13 — Macintosh Plus GCR sector loader

M2.13 advances the Macintosh Plus bring-up from M2.11's raw IWM byte path to a minimal decoded sector loader.

## Scope

The firmware:

- preserves the cumulative reset-overlay, RAM/vector, framebuffer, VIA and keyboard bring-up;
- verifies inserted media through the IWM sense path;
- selects head 0, starts drive 1, enables the IWM and enters Q6=0/Q7=0 read-data mode;
- searches the raw track stream for the Macintosh GCR data address mark `D5 AA AD`;
- requires sector number 0;
- translates the 64 legal GCR symbols;
- reconstructs the 527-byte checksum-domain record used by the classic Macintosh GCR format;
- reverses and validates the rolling checksum transform;
- copies the 512-byte sector payload, excluding the 12-byte tag area, to RAM at `0x00002000`;
- checks that the project-owned payload begins with `LR12`;
- emits `SEC2` and `CHK2` only after a successful load and checksum validation.

Failure paths emit `FAI2` plus a more specific reason marker such as `RDF2`, `CKF2`, or `PLF2`.

## Clean-room qualification media

The CI qualification creates a fresh 400 KiB single-sided Macintosh PSI image with PCE's image tooling. Sector `c0/h0/s0` is populated with a 512-byte payload generated by LibreROM's qualification script. The payload begins with `LR12BOOT-LIBREROM-SECTOR0` and the remainder is deterministic synthetic data.

No Apple ROM, Apple System software, disk image, source, disassembly, or copied binary material is used.

## Independent model

Qualification uses PCE pinned at:

`371414f8f41ae02e9ce36004ba7b076fdd3abe63`

The independently implemented PCE Macintosh GCR encoder documents the framing used for qualification: address mark `D5 AA 96`, data mark `D5 AA AD`, one encoded sector-number symbol, and the encoded checksum-domain body. LibreROM implements its own 68000 decoder from that public behavior rather than copying emulator code.

## PASS criteria

The PCE run must reach `_m2_13_stop` and show:

- `IN12` and `IWMP`/`IWM2` bring-up markers;
- `SEC2` and `CHK2` in low RAM;
- no `FAI2` marker;
- `LR12BOOT` at RAM address `0x00002000`.

The evidence bundle records the pinned PCE commit, fixture hashes, ROM hash, load address, payload size, and runtime transcript.

M2.13 deliberately stops after loading and validating sector 0. Transfer of control to loaded code belongs to a later milestone.


## M2.13 control-transfer delta

M2.13 extends the qualified M2.12 sector loader with a minimal project-owned boot contract. Sector 0 begins with `LR13`, big-endian entry `0x00002010`, and project-owned 68000 code. After decode/checksum/copy, firmware validates the entry, stops IWM, restores VIA DDRA, writes `XFR3`, and jumps to RAM. The fixture writes `BT13` at `0x448` and executes `STOP #0x2700`; PCE breaks at `0x201c` and requires both markers. No Apple ROM, System software, boot block, or derived binary is used.
